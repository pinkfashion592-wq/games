# Games (Antigravity-built)

Browser-based games built with Google Antigravity CLI (`agy`).

## 🐍 Neon Snake (নিয়ন স্নেক)
- File: `snake/index.html`
- Single self-contained HTML, no dependencies.
- Controls: Arrow keys / WASD, on-screen D-pad, swipe. Space = pause, R = restart.
- Bengali UI (স্কোর / সর্বোচ্চ / লেভেল), speed up every 5 foods, Web Audio sounds.

### Play
Open `snake/index.html` in any browser, or visit the GitHub Pages URL.
